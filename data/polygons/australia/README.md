# Australian Polygons

The files `AustralianPolygons.kml` and `SnappedLangs.gpkg` were taken from Bowern's supplementary materials for
*The Oxford Guide to Australian Languges (2023)*, available on Zenodo
at [Files for Australian Language Locations](https://zenodo.org/records/4898185).

The corresponding `.csv` files are the polygon metadata (names of languages, subfamily, `fid` etc.) for the polygons in
those files.

The `pamanyungan-polygons.csv` is a mapping made by me between the 306 languages in the *CHIRILA (Bowern 2016)* dataset
(i.e. those represented in the *Pama-Nyungan* phylogeny) and the file and key to find their polygons.
